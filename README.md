# Quantiz 2026 — Supply Chain War Room

This is a static executive dashboard built from the validated dashboard master workbook.

Open `index.html` locally or deploy the folder to GitHub Pages. The page contains the presentation data needed for the charts; the Excel is included as an audit/source workbook.

Management metadata follows the dashboard notebook logic: the archive management action is surfaced as the management action/state, while Strategic_Action, owner, horizon, trigger and shipment rationale come from the validated decision data/metadata.
